# 📊 Sales Data Analysis Project

## 📌 Project Overview
This project performs data analysis on a sales dataset to extract meaningful insights using Python.

## 🎯 Objectives
- Analyze sales performance
- Identify top products
- Study regional sales distribution
- Visualize trends using charts

## ⚙️ Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 📂 Dataset
The dataset contains:
- Date
- Product
- Quantity
- Price
- Region
- Total_Sales

## 🔄 Steps Performed
1. Data Loading
2. Data Cleaning
3. Data Analysis
4. Data Visualization

## 📊 Visualizations
- Bar Chart → Top 5 Products
- Line Chart → Sales Trend
- Pie Chart → Region-wise Sales

## 📈 Key Insights
- Product X has highest sales
- Region Y contributes most revenue
- Sales peak observed in month Z
